# DefiFable

A simple DefiFable engine for Event driven architecture.

DefiFable is built to be simple and practical, focusing on doing one thing well.

**Why DefiFable?**

- A simple DefiFable engine for Event driven architecture

## Key Features

- A simple DefiFable engine for Event driven architecture

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiFable.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure DefiFable, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
